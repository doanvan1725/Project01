# PC Cleaner

Ung dung Python don dep Windows theo huong an toan:

- quet file tam va cache pho bien
- thong ke so file, dung luong va nhom du lieu
- chon/bat chon tung file hoac tat ca
- highlight file se duoc don de xem lai truoc
- dua file vao Recycle Bin thay vi xoa vinh vien
- ghi log ra file va build EXE portable tren GitHub Actions
- EXE co icon rieng va khong can cai dat vao o C

## Chay local

```bash
pip install -r requirements.txt
python main.py
```

## Luu y

App chi quet cac thu muc temp/cache an toan duoc dinh nghia san. Khong nen xoa cache khi ung dung lien quan dang chay.
